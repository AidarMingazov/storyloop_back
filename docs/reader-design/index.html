Читалка · режимы, слово, голос

История на весь экран, язык по касанию

Три режима над одним эпизодом. «Чтение» — вертикальный комикс. «Движение» — сцена с голосом. «Практика» — реплики по одной. Перевод слова выезжает снизу и не закрывает пузырь, в котором слово сказано.

  • Нажмите на любое слово в пузыре.
  • Нажмите на пузырь мимо слов: появится перевод всей реплики и кнопка голоса.
  • Кнопка ▶ внизу включает озвучку с подсветкой реплики и слова. Голос — синтез браузера, если в системе есть корейский; иначе подсветка идёт без звука.
  • KO · A2 открывает язык, уровень, романизацию, размер текста и тему.
  • Переключатель вверху меняет режим и сохраняет место в эпизоде.

Кадры настоящие: их нарисовал AI-конвейер волны 6. Сюжет «Two Cups», корейские реплики и разметка слов написаны для макета в формате episode.json, поэтому карточка слова собирается из тех же полей, что и сейчас.

Аудит

Что есть в storyloop_back сейчас

Rails 8.1, Stimulus и importmap без сборщика, Tailwind v4 с токенами в @theme. Читалка — ванильные модули app/javascript/reader/*: страница встраивает JSON эпизода (EpisodePayload), клиент рисует четыре формата — webtoon, manga, illustrated, chat.

Оставляем

  • Один JSON на эпизод, тот же в API v1. Новые режимы — это новые рендереры, бэкенд не меняется.
  • Пузыри — HTML поверх кадра по box в процентах, шрифт от ширины кадра (cqw), fitBubbles возвращает вылезшие.
  • У токена есть всё для карточки: перевод в контексте, заметка, романизация, разбор, вежливость, CEFR. Открывается без запроса к серверу.
  • Стиль A «Бумага и маркер», ночная тема до первой отрисовки, safe-area, цели 44px, prefers-reduced-motion.

Мешает премиальному виду

  • Эмодзи вместо иконок: 🔊 ⇄ ✍️ 🔒.
  • Кружки ⇄ и 🔊 висят на каждом пузыре поверх рисунка.
  • Шапка не прячется и вмещает пять вещей; настройки — чекбоксы под ней.
  • В ночной теме два акцента (коралл для тапа, фиолетовый для сохранённого), в светлой акцент чёрный: у тем разная логика цвета.
  • Главная — текстовые карточки со списком эпизодов, без обложек.

Нет под бриф

  • Переключателя режимов и режима «Практика».
  • Плеера: озвучка по одному пузырю, без очереди, скорости, подсветки и Media Session.
  • Десктопа: колонка 640px, без боковой панели; клавиши есть только у манги.
  • Японского и китайского: шрифты Latin + KR, руби только для романизации.
  • Экранов Discover, Story Details, Library и генератора в новом виде.
Уже решается в соседних волнах

Движение — волна M (docs/motion-research.md, её пишет параллельная сессия): panels.motion, камера, эффекты, звук, выборы. Макет следует её решениям: по умолчанию «Чтение», в «Движении» реплика идёт блоком под кадром, а не пузырём.

Смена языка истории — перевод эпизода из 7.8 (origin_episode_id): пилюля «KO · A2» показывает, в каких языках и уровнях есть этот эпизод.

Режимы

Одно место в эпизоде, три способа читать

Режим — отдельный рендерер того же EpisodePayload. Переключение сохраняет сцену и реплику, плеер продолжает с того же места. Каждый телефон ниже живой.

Чтение

Read · по умолчанию

Кадры во всю ширину, пузыри поверх рисунка. Шапка уходит при прокрутке вниз и возвращается при прокрутке вверх или тапе по кадру. Плеер ведёт по репликам и докручивает к говорящему. Если читатель листает сам, докрутка выключается и появляется «Back to the voice».

Движение

Motion · всегда тёмный

Кадр 4:5 с медленным наездом камеры, сверху — сегменты сцен. Реплика блоком под кадром: портрет, имя, текст, субтитр. Тап по кадру — пауза, тап по слову — пауза и карточка; реплика поднимается над шторкой, кадр гаснет. Движок, эффекты и звук — волна M.

Практика

Interactive

Сцена сверху, реплики списком: оригинал, романизация, перевод скрыт до нажатия, «0.7×» для медленного повтора. Внизу слова сцены с отметкой сохранённых. Сюда же лягут выборы сюжета из волны M (M.7) и запись своего голоса.

Слово

Перевод не перекрывает реплику

На телефоне — шторка снизу без затемнения: читалка докручивает так, чтобы пузырь со словом остался над ней, а прокрутка дальше закрывает шторку. На десктопе — поповер у слова и клавиши S и L. Содержимое одно, собирается из полей токена.

Телефон: шторка

До 66% высоты, листается внутри. Пузырь со словом остаётся видимым над шторкой. Закрывается тапом по кадру, свайпом вниз или прокруткой больше 160px.

Десктоп: поповер

320px, открывается под словом, у нижнего края — над ним. Не модальный: читать и прокручивать можно с открытым поповером. Esc закрывает.

  1. Слово как в тексте и романизация — token.surface, token.romanization; рядом голос слова.
  2. Часть речи, уровень, вежливость — lexeme.pos, lexeme.cefr_level, token.politeness.
  3. Перевод в этом контексте, крупно — token.translation.
  4. Словарная форма — lexeme.lemma, lexeme.translation; только если отличается от слова в тексте.
  5. «In this sentence» — token.note.
  6. «How it’s built» — token.breakdown: основа, суффиксы, окончание.
  7. Сохранить и прослушать реплику — user_words, bubble.audio_url.
Аудио

Плеер знает, кто говорит

Мини-плеер живёт в режиме «Чтение»: портрет говорящего, реплика, назад и вперёд по репликам, пауза, скорость. Озвучка — файлы MiniMax через <audio>, поэтому играет и при выключенном экране; синтез браузера остаётся запасным.

  • Подсветка слова сначала считается по длине слова. В волне M появляется audio_ms у реплик; если TTS отдаст тайминги слов, подсветка станет точной.
  • Ручная прокрутка во время озвучки выключает докрутку до нажатия «Back to the voice».
  • Экран блокировки и наушники — Media Session API: обложка-кадр, название сцены, кнопки «реплика назад / вперёд».
  • Скорость: 0.75×, 1×, 1.25×, 1.5×. В «Практике» отдельная кнопка 0.7× на каждой реплике.
Десктоп

Колонка в центре, словарь сбоку

От 1024px: слева сцены эпизода, в центре колонка комикса до 540px, справа словарь эпизода и сохранённые слова. Клавиши работают, когда фокус внутри читалки: кликните по макету.

Система

Бумага днём, полночь вечером

Развитие текущего стиля A и ночной темы D: те же шрифты и маркер. Меняется логика цвета. Один акцент на обе темы — фиолетовые чернила для действий, голоса и прогресса. Маркер — единственный «учебный» цвет. Пузыри всегда бумажные. «Движение» всегда тёмное.

Письменности

План

Четыре волны до новой читалки

Бэкенд, JSON эпизода и API не меняются. Компоненты — CSS-классы в @layer components, ERB-партиалы для серверных частей и JS-сборщики в reader/ для клиентских; без ViewComponent и новых библиотек. В каждой волне — системные тесты на 375×812 и 1280×800.
