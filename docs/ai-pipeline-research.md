| 2. Картинки серии | **Seedream 4.5** `seedream-4-5-251128` | Seedream 5.0-pro `dola-seedream-5-0-pro-260628` | персонажи узнаваемы по листам во всех кадрах; 200 картинок бесплатно |

| 5. Озвучка | **MiniMax `speech-2.8-turbo`**, `language_boost: Korean` | MiniMax `speech-2.8-hd` | ~2 с на реплику, корейский символ = 1 символ оплаты |

Подключено и проверено: DeepSeek (напрямую), BytePlus ModelArk (Seedream; режим Free Credits Only, платные 5.0-pro/5.5 активированы, но на паузе), MiniMax (ключ **M Plan** — кредиты M Plan не работают с pay-as-you-go ключом), OpenRouter (Claude, Qwen, Gemini, DeepSeek).
Отказались: **Alibaba Cloud / Qwen напрямую** — страна аккаунта фиксируется при регистрации, SMS только на её код; Qwen через OpenRouter медленный (60–98 с) и хуже размечает (знаки препинания внутри слов, опечатки).

Подводные камни, которые надо учесть в 6.1:
- OpenRouter резервирует кредиты под `max_tokens` — всегда передавать `max_tokens`, иначе 402 при небольшом балансе.
- DeepSeek V4.1 Flash по умолчанию «думает»: 70–85% выходных токенов — reasoning, отсюда 30–70 с на сценарий. Для разметки и сценария это терпимо (фоновые job'ы).
- DeepSeek: пиковые часы 01–04 и 06–10 UTC по будням — цена ×2. Ночные/выходные прогоны дешевле.
- MiniMax: `base_resp.status_code` ≠ 0 при HTTP 200 (например, 1008 insufficient balance) — проверять тело ответа.
- Seedream: URL картинки живёт 24 ч — сразу скачивать в Active Storage.

Задержки: сценарий 30–70 с, разметка ~50 с на 15–20 реплик (одним запросом), кадр 30–40 с (параллелится), озвучка ~2 с на реплику → эпизод ≈ 3–5 мин при параллельных картинках.

## 3. Шаблоны (на согласование)

```
db/templates/ai/
  voices.yml                        # роли → голоса MiniMax (черновик, выбраны на слух)
  prompts/scenario.md.erb           # system --- user; переменные: cefr, genre, tone, characters, panels, previous, brief
  prompts/markup.md.erb             # правила токенов = конвенции сидов (민호예요 → 민호/noun, 예요 — ending)
  series/office-romance.yml         # Office Crush · 사내 연애, A2: Seoyeon / Dohyun / Mina
  series/office-romance/characters/*.jpeg
  series/folk-golden-axe.yml        # The Golden Axe · 금도끼 은도끼, A1: Woodcutter / Mountain Spirit / Neighbor
  series/folk-golden-axe/characters/*.jpeg
```

Формат серии = `series` из `config/schemas/episode.json` + три поля конвейера: `tone` (в промпт сценария), `art_style` (только манера рисунка — для листов, без локаций), `sheet` (путь к листу персонажа). Предложение для 6.1: в схеме/модели `Character` — Active Storage `sheet`, в `Series` — `tone`, `art_style`; решение за основной сессией (схема общая с импортёром).

Что выяснилось про промпты:
- **Листы персонажей**: в промпт листа нельзя класть полный `style_prompt` серии — модель рисует офис/закаты вместо серого фона и теряет детали (очки). Отсюда `art_style`.
- **Кадры**: листы передаются референсами, в промпте «Image N is the character sheet of NAME»; персонажи ищутся в `image_prompt` по имени. Узнаваемость высокая; слабее — эмоции (холодный взгляд → улыбка), мелкие предметы (серебряный/железный топор), иногда аксессуары «перетекают» между персонажами, кто кого ведёт за руку.
- **Текст на картинке**: «no text» работает, кроме сцен с меню/вывесками — тогда 5.0-lite рисует корейские надписи с ошибками. В сценарном промпте уже запрещены экраны и вывески; в 6.4 добавить проверку `image_prompt` на «menu/sign/board».
- **Сценарий**: исправить в промпте — у духа в сказке смешаны 반말 и 해요체 («나무꾼아, 왜 울어요?»), повелительное «남아요» вместо «남아 주세요». Правило: «один персонаж = один уровень вежливости на весь эпизод, указан в листе персонажа» (добавить `speech_level` в персонажа).
- **Голоса**: рассказчик сказки совпал с голосом духа — у рассказчика должен быть свой голос в серии (`narrator_voice`).
- **Детские сказки как стартовый контент** (идея пользователя): сюжет знаком → A1 понятнее; народные сказки — public domain. «Золотой топор» целиком: 12 кадров, мораль в конце. Кандидаты дальше: 해님 달님, 흥부와 놀부, 토끼와 거북이, 콩쥐팥쥐, 선녀와 나무꾼.

## 4. Разметка слов (6.6 / 6.10)

Прогон 15 реплик из двух эпизодов одним запросом, `prompts/markup.md.erb` (правила = конвенции сидов, один пример из `ko-en/01`). Автопроверки (`markup.rb`): surface найден по порядку, нет пунктуации в surface, все хангыль-слова покрыты, лемма глагола/прилагательного на 다.

| Модель | Время | Цена | Автопроверки | Ручная проверка |
|---|---|---|---|---|
| DeepSeek flash | 50 с | $0.006 | 15/15 | 1 неверная лемма (시작됐어요 → 시작하다), романизация с ошибками (namukkkuneun, dokki reul), странный breakdown (의 → ㅔ) |
| Claude Haiku 5.5 | 50 с | $0.007 | 15/15 | чисто; romanization по произношению (haengbokage) |
| Claude Sonnet 5.5 | 58 с | $0.112 | 15/15 | чисто; разница с Haiku в мелочах (행복하게 → adverb) |

Вывод: с промптом по конвенциям сидов все три модели дают почти одинаковые леммы/части речи (12 из 15 реплик совпали полностью). **Haiku — основной**, DeepSeek — запасной. В 6.6 добавить: проверку offsets/покрытия (как выше) → повтор с ошибками; романизацию лучше считать детерминированно в Ruby по правилам RR, а модель использовать только для произношения-исключений.

## 5. Позиции пузырей (6.5) — не исследовалось

Предложение без AI: промпт кадра оставляет верхние ~25% «спокойными»; авто-раскладка ставит пузыри сверху по порядку реплик (2 пузыря — лесенкой слева-справа), правка процентов `box` в админке. Vision-модель для поиска пустого места — после PoC, если ручной правки окажется много.

## 6. Комикс из своих фото (7.11)

Проверено на 3 фото пользователя (один человек: пляжный бар, медитация у стринг-арта, вейкборд). Исходники в `tmp/ai_probe/photos/`, удаляются после проверки.

1. **Vision** (3 фото одним запросом, JSON: место, субъекты с внешностью для листа, «один и тот же человек», идеи сюжета):

   | Модель | Время | Цена | Качество |
   |---|---|---|---|
   | Claude Sonnet 5.5 | 16 с | $0.026 | самое подробное, связал одного человека на 3 фото |
   | Gemini 3.8 Flash | 13 с | $0.009 | кратко и верно, связал |
   | Claude Haiku 5.5 | 11 с | $0.001 | верно, но **не связал** одного человека |
   | Qwen 3.8 Flash | 60 с | $0.002 | медленно, возраст «unknown» |

   Выбор: Gemini Flash (баланс) или Haiku + отдельный вопрос «это один человек?». Промпт запрещает угадывать личность, этничность и чувствительные признаки.
2. **Фото → лист персонажа**: Seedream 4.5 — полуфотореализм на ростовых видах и потеря бороды на крупных планах. **Seedream 5.0-lite с одним лучшим фото** — ровный 2D-лист, узнаваем во всех 4 видах. Ключ промпта: «NOT photorealistic in any view» + перечислить отличительные черты.
3. **Консистентность в 4 кадрах разных сцен** (кафе, пляж, медитация, Ханган): узнаваем везде. Огрехи: в кафе — меню с искажённым корейским текстом, на воде — скейт вместо вейкборда.
4. **Место с фото → фон**: пляжный бар и комната со стринг-артом перенесены в стиль точно (фото места как второй референс).
5. **Сюжет из фото**: описания сцен → `scenario.rb` → внятная A2-история на 8 кадров («Три дела в выходной»: пляж → уснул на медитации → страшно, но весело на воде), $0.003, 29 с.
6. **Фильтры безопасности**: ни Seedream, ни vision-модели не отклонили фото реального взрослого человека. Не проверено: дети, несколько людей на фото, известные люди — нужно до запуска 7.11 (и правило продукта: только свои фото / с согласием, хранить исходники минимально).

Стоимость комикса из фото (8 кадров): vision до $0.03 + лист $0.035 + кадры 8 × $0.035 + сценарий/разметка/озвучка ≈ $0.03 → **≈ $0.35**.
