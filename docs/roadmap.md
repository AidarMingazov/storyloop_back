# Storyloop — роадмап MVP по волнам

Обновлено: 2026-11-21. Статус: волны 0 и 1 сделаны (кроме аккаунтов 0.2–0.3 и вычитки 0.4).

## Допущения для сроков

- Один разработчик (ты, senior Rails) full-time + Claude Code. Оценки — **рабочие дни**.
- Старт — **пн 23 ноября 2026**. Новогодние **1–8 января 2027** — нерабочие.
- В оценки не входит ожидание внешнего: верификация аккаунтов провайдеров, Stripe, домен, вычитка корейского носителем.
- Волна заканчивается демо: что-то можно открыть и проверить руками. После каждой волны тесты зелёные, `docker compose up` работает.
- `∥` в таблице — задачу можно делать параллельно с соседними (в отдельной сессии/ветке), зависимостей нет.

## ★ Тест спроса — параллельно с волнами 5–6

- 28 дек: мягкий запуск на 50–100 знакомых, правки 28–31 дек.
- с 11 янв: платный трафик. Минимум 2–3 недели, чтобы увидеть D1 и D7 у нескольких когорт.
- Смотрим: дочитывание эпизода, доход до 3-го эпизода, D1/D7, клики «Оплатить», email в листе ожидания.
- Новогодние праздники искажают retention, поэтому основной трафик — после 11 января.

## Главные риски для сроков

| Риск | Влияние | Что делаем |
|---|---|---|
| Ручные сиды (особенно корейский) дольше, чем кажется | +1–2 дня в волне 1 | Черновик с Claude, вычитка носителем (0.4) |
| Позиционирование пузырей на разных экранах | +1–2 дня в волне 2 | Проценты от картинки + `clamp()` для шрифта, системные тесты на 3 ширинах |
| Дешёвые модели плохо размечают корейский | +2–3 дня в волне 6 | Сильная модель только на шаг разметки, остальное — дешёвыми |
| Консистентность персонажей на картинках | +2–3 дня в волне 6 | Референсы + лист персонажа; сравнение двух провайдеров |
| Доступ/оплата китайских API | дни ожидания | OpenRouter как запасной шлюз, начать регистрацию в волне 0 |
| Мало контента для теста спроса (6 эпизодов) | слабый сигнал D7 | До волны 6 дописать эпизоды вручную с Claude по тому же JSON |
