# Storyloop — каналы маркетинга (предложение, ждёт «ок»)

Обновлено: 2026-11-21. После согласования переносим решения в `mvp-research.md` (§0) и `roadmap.md`.

## Главная идея

**Продукт сам является контентом.** Один AI-конвейер (волна 6) выпускает эпизод для приложения и сразу 3–5 вертикальных роликов из него.
Контент-завод — это не отдельный проект, а шаг 6 того же конвейера: «эпизод → ролики → очередь публикаций».

```
AI-конвейер → эпизод в читалке
            └→ 3–5 роликов 9:16 → очередь в админке → TikTok / Reels / Shorts → ссылка → лендинг или стор
                                                          ↑                                  │
                                         метрики роликов ← UTM на каждый аккаунт и ролик ←───┘
```

## 1. Контент-завод (TikTok / Reels / Shorts)

**Формат ролика** (15–45 сек, 1080×1920):
- кадры вебтуна прокручиваются вертикально, пузыри с корейским текстом;
- озвучка реплики (тот же TTS, что в приложении);
- ключевое слово подсвечивается маркером, всплывает перевод и романизация;
- в конце — клиффхэнгер: «Чем закончилось — в приложении / ссылка в профиле».

**Рубрики** (каждая = отдельный аккаунт-ниша, чтобы понять, какая заходит):
1. Мини-дорама сериями: офисный роман, школа, айдол — 1 эпизод = 3–5 частей.
2. «Фраза из K-драмы»: одна реплика, разбор, 3 варианта употребления.
3. «Угадай перевод»: вопрос в первые 2 секунды, ответ в конце.

**Объём:** 3–5 аккаунтов × 1–3 ролика в день. Это 100–300 роликов за 3 недели теста → нужен AI-конвейер, вручную столько не сделать.

**Как делаем технически (Rails, без Node):**
- страница рендера `/render/clips/:id/beats/:n` в 1080×1920 на тех же стилях и пузырях, что у читалки;
- скриншоты кадров через headless Chrome (Ferrum) → `ffmpeg`: склейка, плавный скролл, озвучка, субтитры → MP4;
- LLM генерирует подпись, хэштеги и 3 варианта хука для первой секунды;
- `Clip` в админке: статус (черновик → одобрен → опубликован), аккаунт, UTM-ссылка, «скачать MP4»;
- метрики роликов на старте — вручную/CSV, потом через API платформ.

**Петля «ИИ двигает сам»** (после PoC): метрики роликов → какие сериалы и хуки выиграли → конвейер генерирует больше похожих → маркетолог одобряет. Это и есть автоматизация каналов вместе с маркетологом.

**Можно начать до кода:** маркетолог заводит и прогревает аккаунты уже в декабре — выкладывает записи экрана читалки с сидовыми эпизодами и проверяет хуки руками.

## 2. Сторы и ASO

**Приложение:** Hotwire Native оболочка iOS + Android (волна 8, урезанная и перенесённая раньше). Чтобы Apple не отклонил как «просто сайт в обёртке» (правило 4.2): нативный таббар, нативная панель слова, push позже.

**Ключевые слова (стартовый набор, проверить в ASO-инструменте):** learn korean, korean webtoon, manhwa, korean stories, k-drama korean, hangul reading, korean comics, AI korean.

**Что настраиваем:**
- iOS: название (30 символов), подзаголовок (30), ключевые слова (100), теги App Store (Apple предлагает их по метаданным, лишние снимаем), подписи на скриншотах;
- **кастомные страницы продукта под ключи** (до 70 на приложение; с июля 2025 участвуют в органическом поиске): отдельная страница под «manhwa», под «k-drama», под «hangul»;
- Google Play: название (30), краткое описание (80), полное описание (4000) — ключи берутся из текста.

**Сроки, которые не зависят от нас:**
- Google Play, **личный** аккаунт: перед публикацией — закрытый тест, 12 тестеров 14 дней подряд. **Аккаунт организации** (нужен D-U-N-S, до ~30 дней) — без этого правила.
- Apple Developer: $99/год, ревью обычно 1–2 дня.
- → Аккаунты разработчика заводим **сейчас** (волна 0), ожидание идёт параллельно с разработкой.

## 3. Аналитика и атрибуция

- Каждый аккаунт и каждый ролик — свой UTM (уже сохраняем в `User.utm`).
- Ссылка в профиле → смарт-ссылка: iOS → App Store (campaign link), Android → Google Play, десктоп → веб-лендинг.
- PostHog (волна 4) + аналитика сторов. Главные метрики канала: просмотры → переходы → дочитал 1-й эпизод → D1/D7.

## 4. Как это меняет роадмап (применю после «ок»)

**Новый порядок:** 1–3 как есть → 4 урезанная → 6 (AI-конвейер, облегчённый) → **V. Видео-завод** → **S. Сторы** → тест спроса.

| Волна | Что | Дни (оценка) |
|---|---|---|
| 1–3 | как в роадмапе | 15 |
| 4 урезанная | гость, онбординг, magic link, fake door, лендинг ko-en, PostHog, деплой. Без PWA | ≈ 7 |
| 6 облегчённая | сценарий, картинки, разметка, озвучка, review. Сравнение провайдеров — минимальное | ≈ 9 |
| **V. Видео-завод** | рендер-страница, Ferrum + ffmpeg, подписи и хэштеги LLM, `Clip` и очередь в админке, UTM | ≈ 5 |
| **S. Сторы** | Hotwire Native iOS + Android, нативный таббар, без пейвола, ASO-метаданные, смарт-ссылка | ≈ 6 + ревью |

**Выкидываем из PoC:** manga и illustrated (5.1, 5.2), JSON API (5.4 — Hotwire Native его не требует), Stripe (7.2), email-напоминания (7.3), PWA (4.9).

**Ориентир:** органические ролики со ссылкой на веб — с середины января; сторы — конец января – начало февраля (с учётом 14 дней теста Google Play при личном аккаунте).
